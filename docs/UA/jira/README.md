# Jira Management

Ця папка містить приклади роботи з Jira під час розробки проєкту QR Food System.

## Що міститься

- Product Backlog
- Sprint Board
- Epics Structure
- User Stories
- Acceptance Criteria
- Task Workflow

## Agile Methodology

Проєкт вівся з використанням Agile/Scrum практик.

Основні процеси:
- пріоритизація backlog
- планування спринтів
- decomposition user stories
- task management
- workflow tracking

## Приклади

### Backlog
Містить структурований product backlog з priorities та sprint organization.

### Sprint Board
Показує workflow statuses:
- TO DO
- IN PROGRESS
- DONE

### User Stories
Приклади:
- As a student, I want to see my balance
- As a user, I want to log in and out

### Acceptance Criteria
Задачі містять структуровані acceptance criteria для перевірки функціоналу.
