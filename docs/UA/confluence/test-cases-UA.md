## QR-код

### TC-QR-01 — Сканування валідного QR-коду

| Поле | Опис |
|------|------|
| **ID** | TC-QR-01 |
| **Назва** | Сканування валідного QR-коду студента |
| **Передумова** | Касир авторизований. Студент має валідний QR-код |

**Кроки:**
1. Студент показує QR-код на касі

3. Система шукає студента в базі даних

## Транзакції

### TC-TR-01 — Успішне замовлення та оплата

| Поле | Опис |
|------|------|
| **ID** | TC-TR-01 |
| **Назва** | Створення замовлення при достатньому балансі |
| **Передумова** | Касир авторизований. Баланс студента достатній |

**Кроки:**
1. Студент показує QR-код
2. Касир сканує QR-код — з'являється профіль студента
3. Касир запитує студента що він хоче замовити
4. Касир обирає страви та кількість на сайті
5. Система розраховує загальну суму
6. Касир натискає "Підтвердити замовлення"
7. Система перевіряє баланс студента
8. Система списує кошти з балансу
9. Касир видає їжу студенту

**Очікуваний результат:** Замовлення створено. Баланс оновлено. Відображається повідомлення про успішну оплату

---

### TC-TR-02 — Замовлення при недостатньому балансі

| Поле | Опис |
|------|------|
| **ID** | TC-TR-02 |
| **Назва** | Створення замовлення коли у студента недостатньо коштів |
| **Передумова** | Касир авторизований. Баланс студента менший за суму замовлення |

**Кроки:**
1. Студент показує QR-код
2. Касир сканує QR-код — з'являється профіль студента
3. Касир обирає страви
4. Касир натискає "Підтвердити замовлення"
5. Система перевіряє баланс студента
6. Балансу недостатньо

**Очікуваний результат:** Відображається повідомлення — "Недостатньо коштів". Замовлення не створено. Баланс не змінено

---

### TC-TR-03 — Оновлення балансу після оплати

| Поле | Опис |
|------|------|
| **ID** | TC-TR-03 |
| **Назва** | Баланс зменшується після успішного замовлення |
| **Передумова** | Баланс студента 100.00 грн. Сума замовлення 70.00 грн |

**Кроки:**
1. Касир створює і підтверджує замовлення на 70.00 грн
2. Система проводить оплату
3. Касир або студент перевіряє баланс

**Очікуваний результат:** Баланс показує 30.00 грн
