# Jira Management

This folder contains Jira workflow examples used during the development of QR Food System.

## Included

- Product Backlog
- Sprint Board
- Epics Structure
- User Stories
- Acceptance Criteria
- Task Workflow

## Agile Methodology

The project was managed using Agile/Scrum practices.

Main activities:
- backlog prioritization
- sprint planning
- user story decomposition
- task management
- workflow tracking

## Examples

### Backlog
Shows structured product backlog with priorities and sprint organization.

### Sprint Board
Demonstrates workflow statuses:
- TO DO
- IN PROGRESS
- DONE

### User Stories
Examples:
- As a student, I want to see my balance
- As a user, I want to log in and out

### Acceptance Criteria
Tasks contain structured acceptance criteria for feature validation.
