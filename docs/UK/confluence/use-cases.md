# Use Cases

## UC-01 Order Meal via QR

### Actors
- Primary: Cook
- Secondary: Student

### Preconditions
- Cook logged in
- Student exists
- Menu exists

### Main Flow
1. Scan QR
2. Show student
3. Select meals
4. Confirm
5. Deduct balance
6. Save transaction

### Alternative Flow
- Student not found
- Insufficient balance
- Cancel order
